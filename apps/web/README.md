# NirikshAI Web Application (`@nirikshai/web`)

The Next.js 15 enterprise web portal for AICTE Regulation Bureau, integrating all 5 user personas:
1. **Technical Institution Portal (`/institution`)**: Self-service application filing, client-side SHA-256 stamping, instant pre-scrutiny checks.
2. **Scrutiny Officer Workspace (`/officer`)**: Split-screen OCR dossier, bounding box overlay, APH 2024–27 clause violation citations.
3. **Senior Scrutiny Committee (`/senior`)**: Macro triage, high-risk escalation review, regional analytics.
4. **Regulation Bureau Admin (`/admin`)**: Declarative handbook rule publishing, institutional master directory onboarding.
5. **Central Vigilance Auditor (`/auditor`)**: Cryptographic SHA-256 hash-chain verification, live tamper detection.

Live Production URL: [https://sih-2k26-2-0.vercel.app](https://sih-2k26-2-0.vercel.app)
