# Security Policy & Vulnerability Disclosure

## Supported Versions
Only the latest major version on the `main` branch receives active security updates.

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability
The NirikshAI engineering team takes regulatory data integrity, DPDP compliance, and cybersecurity seriously.

If you discover a security vulnerability in NirikshAI:
1. **DO NOT** create a public GitHub issue.
2. Email full technical details to **security@nirikshai.gov.in** with the subject line `[SECURITY DISCLOSURE] Vulnerability in NirikshAI`.
3. Include reproducible proof-of-concept steps, affected files, and potential impact.
4. We acknowledge receipts within 24 hours and issue CVE or coordinated patch advisories within 7 days.
